# Library Book Management API

A RESTful API built using **Node.js, Express, and MongoDB (Mongoose)** to manage library books with full **CRUD operations** and **error handling**.

---

## Objective
To build a backend API that:
- Manages books in a library
- Supports CRUD operations
- Prevents invalid updates
- Handles errors properly

---

##  Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
